# Contributing

Copybara's application code is private, so we don't take code contributions. You can still help a lot:

- **Report bugs.** [Open a bug report](https://github.com/CopybaraTrading/CopybaraTrading/issues/new?template=bug_report.yml). The more detail, the faster we can fix it.
- **Suggest features.** [Share an idea](https://github.com/CopybaraTrading/CopybaraTrading/issues/new?template=feature_request.yml), or tell us on [Telegram](https://t.me/CopybaraTrades).
- **Improve the docs.** If something here is wrong or unclear, open an issue or a pull request against this repository.
- **Report security problems privately.** See [SECURITY.md](SECURITY.md). Never in a public issue.

Please never post private keys, seed phrases, sign-in codes or screenshots that show them.
