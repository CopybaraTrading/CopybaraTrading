# Fees

| What | Copybara's fee | Other costs |
|---|---|---|
| **Copied trade** (buy or sell) | 0.5% of the trade | The network fee, and any fee the exchange or token itself charges |
| **Your own sale** from Positions | 0.5% of the sale | The network fee |
| **Swapping** a chain's dollars and its own coin on the Wallet page | None | The network fee and the exchange's own fee |
| **Moving money between chains** | None | The bridge's own fee and network fees |
| **Deposits and withdrawals** | None | The network fee |
| **Polymarket bet** | 0.5% of each bet, added by Polymarket | None: Polymarket pays the network fee |

- **No subscription,** and no fee on profits.
- **Only on trades that go through.** A trade that fails or is skipped costs no Copybara fee. A failed transaction can still cost a network fee.
- **Where possible, the fee is taken inside the swap,** so you can see it in the transaction.
- **Network fees** go to the chain's validators, not to Copybara. They are paid in the chain's own coin (ETH, SOL, HYPE…).
- **Token taxes.** Some tokens charge their own tax on every buy or sell. That goes to the token, not Copybara, and is part of the price you get.
